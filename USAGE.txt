WebDL - wget-style Website Downloader
=======================================

QUICK START
-----------

Just run it! No setup required - it auto-configures everything:

  python3 webdl.py example.com

First run will:
- Create a virtual environment (venv/)
- Install all dependencies automatically
- Start downloading the site

Downloaded sites are saved to: sites/example.com/


USAGE EXAMPLES
--------------

Basic usage (download entire site):
  python3 webdl.py example.com

Download with custom limits:
  python3 webdl.py example.com --max-depth 5 --max-pages 200

Download without git commits:
  python3 webdl.py example.com --no-git

Download with verbose logging:
  python3 webdl.py example.com --verbose

Download from specific URL:
  python3 webdl.py https://example.com/docs/

Re-download to update existing site:
  python3 webdl.py example.com
  (Updates changed files, commits changes to git)

Parallel downloads (multiple terminals):
  Terminal 1: python3 webdl.py example1.com
  Terminal 2: python3 webdl.py example2.com
  Terminal 3: python3 webdl.py example3.com


COMMAND LINE OPTIONS
--------------------

positional arguments:
  domain                Domain or URL to download (e.g., example.com)

optional arguments:
  --max-depth N         Maximum crawl depth (default: 10)
  --max-pages N         Maximum number of pages (default: 1000)
  --no-git              Skip git commit after download
  -v, --verbose         Enable verbose debug logging
  -h, --help            Show help message


FEATURES
--------

- Auto-setup: First run creates venv and installs dependencies automatically
- Humanized downloading: Random delays, browser-like headers, avoids bot detection
- Recursive crawling: Follows all internal links up to specified depth
- Link conversion: All links converted to relative paths for offline viewing
- Contact extraction: Automatically extracts emails, phones, social media handles
- Organized storage: Files saved to sites/domain/ with proper directory structure
- Per-site git repos: Each site gets its own git repo for tracking changes
- Smart .gitignore: Heavy files (images, videos, PDFs) excluded from git
- Auto-commit: Changes committed automatically after each download
- Incremental updates: Re-run to update existing site with new content
- Parallel safe: Run multiple downloads simultaneously without conflicts
- Portable: No hardcoded paths, works anywhere
- Resource downloading: Downloads CSS, JS, images, fonts, and other assets
- No robots.txt: Downloads regardless of robots.txt restrictions
- Clean structure: All files under 300 lines, modular design

PER-SITE GIT REPOSITORIES
-------------------------

Each downloaded site gets its own git repository automatically!

Tracked files (in git):
- HTML files (.html, .htm)
- CSS stylesheets (.css)
- JavaScript files (.js, .json)
- Text files (.txt, .xml)
- Fonts (.woff, .woff2, .ttf, etc.)

Excluded from git (heavy files):
- Images (.jpg, .png, .gif, .svg, .webp, etc.)
- Videos (.mp4, .avi, .mov, .webm, etc.)
- Audio (.mp3, .wav, .ogg, etc.)
- PDFs (.pdf)
- Archives (.zip, .tar, .gz, etc.)

View site changes:
  cd sites/example.com
  git log                    # See all updates
  git diff HEAD~1            # Compare with previous version
  git show                   # View last commit changes


CONTACT EXTRACTION
------------------

Every download automatically extracts contact information and saves it to
contacts.json in the site directory. This file is tracked in git!

Extracted information:
- Email addresses (with validation to exclude placeholders)
- Phone numbers (normalized format)
- Twitter handles
- LinkedIn profiles
- Facebook profiles
- GitHub accounts
- Instagram handles

The extractor:
- Scans all HTML files in the downloaded site
- Scans git history for contacts in previous versions
- Deduplicates contacts (no duplicates added)
- Updates existing contacts.json on each run
- Excludes common placeholder emails (example.com, test.com, etc.)

View extracted contacts:
  cat sites/example.com/contacts.json

Example contacts.json:
  {
    "domain": "example.com",
    "last_updated": "2025-11-06T12:00:00.123456",
    "emails": [
      "contact@example.com",
      "support@example.com"
    ],
    "phones": [
      "+15551234567",
      "15559876543"
    ],
    "social_media": {
      "twitter": ["example_twitter"],
      "linkedin": ["company/example"],
      "facebook": ["example.page"],
      "github": ["example-org"],
      "instagram": ["example_official"]
    }
  }

Contact extraction runs automatically after each download as Phase 3,
before git commit. This means all extracted contacts are committed to
the site's git repository for tracking changes over time.


VIEWING OFFLINE
---------------

After downloading, simply open any HTML file in your browser:

1. Navigate to: sites/example.com/
2. Open index.html in your browser
3. All links will work correctly for offline viewing


PARALLEL DOWNLOADS
------------------

You can run multiple downloads at the same time safely:

  # Terminal 1
  python3 webdl.py site1.com

  # Terminal 2
  python3 webdl.py site2.com

  # Terminal 3
  python3 webdl.py site3.com

Each site has its own directory and git repo, so they won't conflict.


ADVANCED USAGE
--------------

Download small site quickly:
  python3 webdl.py example.com --max-depth 3 --max-pages 50

Download large documentation site:
  python3 webdl.py docs.example.com --max-depth 15 --max-pages 5000

Download without git tracking:
  python3 webdl.py example.com --no-git

Debug crawling issues:
  python3 webdl.py example.com --verbose

Update existing site:
  python3 webdl.py example.com
  (Downloads new content, updates changed files, commits to git)

  The sites/ directory contains standard HTML/CSS/JS files
  that can be processed with any Python tools (BeautifulSoup, etc.)

Track site changes over time:
  cd sites/example.com
  git log --oneline          # Compact history
  git diff @{1.day.ago}      # Changes since yesterday
  git log --stat             # See which files changed


TECHNICAL DETAILS
-----------------

Auto-Setup:
- Detects if running in virtual environment
- Creates venv/ if doesn't exist
- Installs dependencies automatically
- Re-executes itself in venv context
- Fully portable - works from any directory

Bot Detection Avoidance:
- Rotates between multiple realistic User-Agent strings
- Random delays between requests (1-3 seconds)
- Browser-like HTTP headers
- Respects server response times

Link Conversion:
- Converts absolute URLs to relative paths
- Handles HTML tags: a, link, script, img, iframe, etc.
- Processes CSS url() references
- Supports srcset and inline styles

Storage:
- Creates sites/domain/ directory structure
- Preserves original URL path structure
- Tracks metadata for incremental updates
- Detects content changes via MD5 hashing

Git Integration:
- Auto-initializes git repo per site
- Creates smart .gitignore for heavy files
- Auto-commits after each download
- Tracks HTML/CSS/JS changes over time
- Each site has isolated git history


LIMITATIONS
-----------

- JavaScript-heavy sites: Only downloads static HTML (no JS execution)
- Authentication: Does not handle login/authentication
- Dynamic content: Cannot capture dynamically loaded content
- File size: Skips files larger than 100MB
- Same domain only: Only downloads from the target domain


TROUBLESHOOTING
---------------

No module named 'requests':
  Just run again - first run auto-installs dependencies

Permission denied:
  Make script executable: chmod +x webdl.py

Download interrupted:
  Just re-run the same command - it will resume and update

Site not loading offline:
  Check that you're opening the index.html file
  Some sites may have absolute URLs that weren't converted

Git not committing:
  Use --verbose to see git errors
  Or use --no-git to disable git integration

Parallel downloads conflicting:
  Each site should have its own directory - shouldn't conflict
  If same domain, second download will update the first


PORTABILITY
-----------

This tool is fully portable:
- No hardcoded paths - uses relative paths
- Auto-creates venv in script directory
- Works from any location
- Just copy the directory and run

To copy to another machine:
  cp -r script_webdl /path/to/destination
  cd /path/to/destination
  python3 webdl.py example.com  # Works immediately!


For more details, check the docstrings in each Python module.
